# Эмулятор языка оболочки ОС

Учебный проект (ИКБО-41-25, Вариант №25). GUI-эмулятор командной
строки на Python + PySide6.

## Методология разработки

Проект ведётся поэтапно по методичке (Вариант №25): каждый этап
задания — это отдельный набор фич, зафиксированный отдельными
коммитами, а не один большой коммит в конце.

- **Инкрементальная разработка.** Функциональность добавляется
  шаг за шагом (сейчас реализован Этап 1 — REPL с заглушками
  команд), каждый шаг — рабочее и протестированное состояние
  программы.
- **Разделение логики и интерфейса.** Разбор команды
  (`parse_command`) и её выполнение (`run_command`) вынесены в
  отдельные функции, не зависящие от Qt/PySide6. Это позволяет
  тестировать основную логику без запуска графического окна.
- **Юнит-тестирование.** Для чистых функций написаны тесты
  (`pytest`), которые гоняются в headless-режиме
  (`QT_QPA_PLATFORM=offscreen`), поэтому их можно запускать и в
  CI, и без дисплея.
- **Git-флоу.** Коммиты атомарны и подписаны в стиле Conventional
  Commits (`feat(...)`, `fix(...)`) — по сообщению коммита видно,
  какой этап или какая правка в нём сделаны.

## Этап 1 — REPL

Сделано:

- окно с логом диалога и строкой ввода;
- заголовок окна вида `Эмулятор - [user@host]`;
- простой разбор ввода на команду и аргументы (`parse_command`);
- команды-заглушки `ls` и `cd` — печатают своё имя и аргументы;
- команда `exit`;
- сообщение об ошибке, если команда неизвестна.

## Установка и запуск

```bash
pip install -r requirements.txt
./run.sh
```

## Тесты

```bash
QT_QPA_PLATFORM=offscreen python3 -m pytest tests -v
```

## Пример работы

```
Эмулятор запущен. Команды: ls, cd, exit
> ls -l
ls: вызвана с аргументами ['-l']
> cd /home
cd: вызвана с аргументами ['/home']
> abc
Ошибка: команда не найдена: abc
> exit
```
